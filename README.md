# GRphoto — Георгий Рожин

Сайт фотографа в Челябинске на Vite, семантическом HTML, CSS и небольшом модуле JavaScript. Требуется Node.js 20.19+ или 22.12+; проверено на Node.js 24.

```sh
npm ci
npm run dev
```

Проверка production-сборки: `npm run build`. Локальный просмотр сборки: `npm run preview`. Для публикации в подкаталоге используйте `npm run build -- --base=/имя-репозитория/`.

## Структура

- `index.html`: первый экран, локации Челябинска, сторонние фото-референсы, варианты съёмки, подготовка, первые съёмки, FAQ и контактный блок.
- `src/style.css`: чёрно-красная палитра, выразительная типографика, адаптивная компоновка, обработка фотографий при отображении.
- `src/main.js`: копирование номера, раскрытие сведений об авторах по обеим якорным ссылкам, отображение настоящих отзывов при наличии данных. FAQ работает нативно через `details`.
- `src/reviews.js`: список реальных отзывов с полями `name`, `text`, `context`. Сейчас пуст: настоящие отзывы пока не предоставлены. Секция скрыта, фиктивные отзывы и имена не публикуются. После добавления согласованных текстов карточки появятся автоматически.
- `public/images/georgiy-portrait.png`: портрет в исходной позе, чёрном пиджаке и с красным боковым светом; черты лица уточнены по новой фотографии пользователя. Прозрачный фон.
- `public/images/chelyabinsk-*.jpg`: реальные фотографии локаций Челябинска с Wikimedia Commons. Это не портфолио фотографа.
- `public/images/reference-*.jpg`: портреты других авторов с Pexels для блока «Можем попробовать». Это не работы Георгия и не фотографии, снятые в Челябинске. Рядом предложены местные локации, под которые можно адаптировать идею.
- `public/images/reference-credits.json`: авторы, страницы оригиналов и лицензия Pexels.
- `public/images/city-credits.json`: источники, авторы и лицензии городских фотографий. Эти же сведения доступны посетителям в подвале сайта.

Контакт предоставлен пользователем: Telegram по номеру +7 908 826-02-36, ссылка `https://t.me/+79088260236`. Возможность найти аккаунт по номеру зависит от настроек Telegram владельца. На сайте также можно скопировать номер.

Manrope и Oswald загружаются локально и поддерживают кириллицу. Лицензии шрифтов: `public/fonts/OFL.txt` и `public/fonts/Oswald-OFL.txt`. Фотографии локаций и их отображаемые адаптации доступны по CC BY-SA 4.0, с атрибуцией в подвале. Портреты-референсы используются по Pexels License, с обозначением стороннего авторства в карточках и подвале. Кнопки референсов открывают Telegram с черновиком сообщения; сообщение не отправляется автоматически. Фиктивных работ, отзывов, показателей опыта и цен нет. Сайт не использует внешние API, формы отправки, аналитику и cookies; внешние ссылки открываются только по действию посетителя.

GitHub Actions собирает и публикует сайт после изменений в `main`. Базовый путь автоматически определяется по имени репозитория. Текущий подтверждённый адрес: https://websitesg.github.io/moyka/. После переименования репозитория в `GRphoto` адрес изменится на https://websitesg.github.io/GRphoto/. Публикацию можно запустить вручную через Actions → Publish website → Run workflow.
