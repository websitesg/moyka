# Георгий Рожин — первый экран

Минимальный сайт на Vite, семантическом HTML и CSS. Требуется Node.js 20.19+ или 22.12+; проверено на Node.js 24.

```sh
npm ci
npm run dev
```

Проверка production-сборки: `npm run build`. Локальный просмотр сборки: `npm run preview`.

Реализован только hero-блок. Авторские фотографии и контакты не предоставлены, поэтому здесь нет стоковых работ и фиктивных кнопок. В `index.html` предусмотрено место для будущей фотографии с комментарием по замене. Основные стили и адаптивная компоновка — в `src/style.css`.

Manrope загружается локально, поддерживает кириллицу. Лицензия шрифта: `public/fonts/OFL.txt`. Страница не обращается к внешним сервисам.
