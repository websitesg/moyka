# GRphoto — Георгий Рожин

Минимальный сайт на Vite, семантическом HTML и CSS. Требуется Node.js 20.19+ или 22.12+; проверено на Node.js 24.

```sh
npm ci
npm run dev
```

Проверка production-сборки: `npm run build`. Локальный просмотр сборки: `npm run preview`.

Реализован только hero-блок: крупная красная надпись «ФОТОГРАФ», имя слева и портрет поверх фоновой типографики. Портрет в `public/images/georgiy-portrait.png` создан по предоставленному пользователем фото лица и дизайн-референсу. Изображение имеет прозрачный фон. Фиктивных проектов, показателей и контактных ссылок нет. Основные стили и мобильная компоновка — в `src/style.css`.

Manrope и Oswald загружаются локально и поддерживают кириллицу. Лицензии шрифтов: `public/fonts/OFL.txt` и `public/fonts/Oswald-OFL.txt`. Страница не обращается к внешним сервисам.

GitHub Actions собирает и публикует сайт после изменений в `main`. Базовый путь автоматически определяется по имени репозитория. После переименования репозитория в `GRphoto` адрес сайта: https://websitesg.github.io/GRphoto/. Публикацию также можно запустить вручную через Actions → Publish website → Run workflow. Для других хостингов используйте `npm run build` и каталог `dist`.
